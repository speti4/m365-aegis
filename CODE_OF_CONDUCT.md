# Code of conduct

m365-aegis adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct, for the issues, pull requests, reports made under the [security policy](SECURITY.md)
and every other project space.

In short: be kind and constructive, assume good intent, and keep criticism about the work, never about the
person. Harassment, insults and personal attacks are not tolerated.

A project space about administering other people's accounts calls for one more rule: never post a tenant's
data here, not a user's name, a mailbox address, an object id, a sign-in record or a token, your own tenant's or
anyone else's. A post that does will be edited or removed.

## Reporting

Report unacceptable behavior with GitHub's *Report content* menu on the comment, issue or pull request. For
anything that needs a private channel to the maintainer (@speti4), the form for a
[private security advisory](https://github.com/speti4/m365-aegis/security/advisories/new) serves as one until the
project has a conduct contact of its own: title it "Conduct report". Reports are handled confidentially. The
maintainer decides on the consequences, following the Covenant's enforcement guidelines, from a warning up to a
permanent ban from the project.
