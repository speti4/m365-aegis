# Small flow fixes in the window

What: a bundle of one-line fixes. Done on a write card either clears the fields or usage.md stops saying it starts
the card over; a failed result states its summary once, the code in a details line, and offers "See the plan again";
a sign-in in progress gets a Cancel instead of a sixteen-minute wait; the lookup button keeps its width while it
reads "Looking up…"; the technical details (the Read through column and its sentence, "answered in", object ids,
error codes) go behind a collapsed Details line; the diff card's fields get labels, a format hint (`latest`,
`yesterday`, a date) and the user picker; table headers smaller and muted, tabular numbers, a fixed column layout.
Why: the UX/UI review of 2026-11-02 (U-9, U-10, U-12, D-12, U-11, D-10, C-12, D-8): none is worth a task alone,
together they are the texture a support colleague meets every day.
Done when: each item is ticked with its check in the mock, and usage.md says what Done does.
